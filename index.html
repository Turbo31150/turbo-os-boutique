QUESTIONS FRÉQUENTES

Questions & Réponses

Quel matériel faut-il pour faire tourner les packs Turbo OS ? +
Une simple machine avec 16 Go de RAM et un processeur récent suffit pour démarrer avec les modèles quantifiés 4-bit (ex: Qwen 2.5 1.5B/3B ou Mistral 7B). Si vous disposez d'un GPU NVIDIA (ex: GTX 1660 Ti, RTX 3060, 3080 ou 4090), vous profiterez d'un débit d'inférence allant de 40 à 120 tokens/seconde en toute fluidité.
Est-ce vraiment 0 € après l'achat ? Aucun abonnement caché ? +
Absolument. Vous achetez les fichiers et le savoir définitivement. Vos inférences se déroulent sur vos propres composants physiques. Aucune clé API payante n'est requise pour exploiter les capacités des packs.
Comment fonctionne Claude Code et les agents CLI ? Utilisent-ils mon abonnement ou le vôtre ? +
Claude Code est une application CLI (ligne de commande) qui s'exécute à 100% en local sur votre machine, exactement comme git, bash ou python. Il ne consomme jamais notre abonnement ni aucun abonnement partagé :
• Mode 100% Souverain (0-Token) : Vous pouvez le brancher directement sur vos modèles LLM locaux (via le proxy local port :1240 / :18800). Il fonctionne alors gratuitement, sans abonnement et sans aucun appel sortant.
• Mode Hybride (Clé personnelle) : Si vous décidez d'utiliser un modèle cloud, vous configurez votre propre clé API personnelle. Vous gardez le contrôle absolu de vos dépenses sans dépendance tierce.
Comment s'effectue le partage de ressources entre machines ? +
Le partage de ressources s'effectue au sein de votre réseau local privé sécurisé (LAN / mTLS chiffré). Vos machines connectées se répartissent les tâches automatiquement (ex: déporter la transcription vocale Whisper sur un GPU dédié pendant que le CPU principal reste libre). Aucune adresse IP publique ni identifiant personnel n'est exposé à l'extérieur. Tout reste cloisonné dans votre périmètre privé.
Comment fonctionne la Table Ronde des 7 Sièges ? +
La Table Ronde connecte 7 agents spécialisés ayant chacun leur domaine d'expertise (infrastructure, rigueur de code, synthèse multimodale, inférence déconnectée, exécution système, gouvernance produit et latence GPU). Lorsqu'un problème lui est soumis, les 7 sièges délibèrent en parallèle, confrontent leurs arguments et synthétisent un consensus opérationnel sans aucune complaisance.
Combien d'extraits je reçois vraiment, et d'où viennent-ils ? +
Vous recevez ce qui est écrit dans le manifeste de chaque pack — au total ~27 700 extraits propres pour le Fonds Complet, que vous comptez vous-même dans corpus.jsonl. Ce sont des retours d'exploitation d'un vrai parc IA local, en création originale. Les extraits rattachés à une source tierce (URL externe ou capture) sont exclus d'office et comptés dans le manifeste (droits non réglés). Usage : interne illimité, revente interdite.
